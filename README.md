# Limitless Chat - Bug Reports & Feature Requests

This repository is the public issue tracker for the Limitless Chat Minecraft mod.

## How to Report a Bug

Click **New Issue** and include:

* What happened
* What you expected to happen
* Your Minecraft version and mod version
* Steps to reproduce

## How to Request a Feature

Click **New Issue** and describe:

* What feature you'd like
* Why it would improve the mod

## How to Request a Version Port

Click **New Issue**, select **Version Request**, and include:

* The exact Minecraft version you want
* The Mod Loader you use (Forge/Fabric/NeoForge)
* (Optional) Why you need this specific version
